## 3. Proposed refactor sequence

Each step is independently shippable, keeps `pnpm typecheck` + `pnpm test` green, and is ordered so later steps get smaller.

1. **Error boundary (F1 + F10, ~2 days).** Add `modules/errors.ts` with `DomainError(code, message, cause)`; rebase the 10 existing error classes on it; add the `errorFormatter` in `trpc/init.ts` (REST/MCP inherit via `getTRPCErrorFromUnknown`); Biome `noRestrictedImports` forbidding `@trpc/server` under `modules/**` (allow-list the 10 current files, burn the list down). Promote `bestEffort` to `utils/` with `log.debug` and replace the 45 `.catch(() => {})`. Ships alone; changes only error codes seen by REST/CLI/MCP (500 → 400/404/409 where modules already validate).
2. **Service registry (F3, part 1, ~3 days).** `modules/services/registry.ts` with the kind tuple + per-kind table/id/module map; derive `serviceType` zod enums and the web `ServiceKind` from it; replace the 8 switch sites (`org.ts`, `tags`, `projects` counts + cascade, `monitoring` fleet, `backup`, `gitops/apply`, web `service-types.ts`, `database-types.ts`) and delete the 8 `any`s that exist only for dynamic kind dispatch. No behaviour change; tenancy suite + gitops tests cover it.
3. **Transactions (F2, ~2 days).** Introduce `type DbExecutor = typeof db | PgTransaction` on the write helpers touched in step 2 (registry makes cascade/tag/move code one function each), then wrap `setServiceTags`, `applyStack`, `duplicate*`, `move*`, project/environment cascade deletes. Swarm/Traefik side effects stay outside via `bestEffort`.
4. **Split the god modules + test utils (F5 + F8, ~4 days, can be 4 separate PRs).** `git/webhook-handler.ts` → `providers/{github,gitlab,bitbucket,gitea}.ts` + `match.ts` (glob/watch paths) + `handler.ts` + `preview-flow.ts`; `compose/compose-file.ts` → `parse.ts`, `interpolate.ts`, `safety.ts`, `rewrite.ts`; `backups/runner.ts` → `s3.ts`, `database.ts`, `redis.ts`, `instance.ts`, `volume.ts`; `monitoring/history.ts` → `store.ts`, `sampler.ts`, `alerts.ts` (and move `mapDockerStats`/`resolveLocalContainer` from `ws/` to `modules/docker/`); `routers/monitoring.ts` host readers → `modules/monitoring/host.ts`. Add `src/test-utils/{fake-db,fake-session,tmpdir}.ts` in the same PRs and delete the per-file mocks the splits make unnecessary. Then add tests for `ws/access.ts`, `schedules/runner.ts` command building, and a capability matrix over routers.
5. **Web form/hook consolidation + duplicate panels (F4 + F13, ~3 days).** `useSaveMutation`, `useDraft`, `useMounted`, `useDebouncedValue`; migrate the 39 save forms (mechanical, one PR per folder); merge `schedules-view`/`schedules-tab` into `SchedulesPanel` and `database-backups`/`volume-backups-tab` into `BackupsPanel`; `ApplicationProvider` + server-component page; move `settings-section.tsx` to `layout/`; delete 5 unused `ui/*` files; Suspense on `/dashboard`.

Deferred until after the above (they get cheaper): `buildServiceRouter` folding `application`/`compose` lifecycle procs (F3 part 2), `buildGitProviderRouter` (F9), shared zod schema package + CLI types from `AppRouter` (F7), web/landing tsconfig strictness (F11).
