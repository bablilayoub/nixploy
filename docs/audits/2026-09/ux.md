# Nixploy web panel — UX / product-experience audit (2026-09-10)

Scope: `apps/web` on branch `work/stability-and-landing`. Bugs already fixed by the stability sweep (docs/status.md) are not repeated; this is about speed, safety and clarity for operators.

## 1. Method

- Drove the real app. Panel started from `apps/web` with `tsx server.ts` on **:3120**, `DATABASE_URL` pointed at the throwaway `nixploy_e2e` database (user `e2e@example.test`), a scratch `NIXPLOY_CONFIG_DIR` (scratch, not kept) and `NIXPLOY_DISABLE_TRAEFIK_BOOT=1`. Server stopped at the end; port 3120 free.
- Playwright (`tools/screenshots/node_modules/playwright-core`) scripts and 98 screenshots (scratch, not kept) (`01`–`20` onboarding + application tabs, `21`–`30` compose / postgres / project tabs, `31`–`42` templates, docker, monitoring, schedules, settings pages + dialogs, `50`–`58` mobile 390 px, `60`–`68` dark mode). tRPC network timing logged (scratch, not kept).
- In the e2e DB I created records only: projects `audit-demo`, `audit-demo-2`, application `demo-app`, compose `demo-stack`, postgres `demo-pg`. One click on **Deploy** for the unconfigured app was part of the "first deploy" walk; the worker rejected it in 15 ms ("Git source requires a gitUrl") — verified no swarm service / Traefik file was created. No org, server, domain or template deploy was created; nothing deleted.
- Pages walked: login, dashboard (empty + populated), project (services / env vars / deployments), application (all 6 tabs, all sub-tabs, Advanced), compose (7 tabs), postgres (6 tabs), templates + deploy sheet, docker, monitoring, schedules + dialog, all 12 settings pages, add-server / add-notification / add-domain / delete dialogs, ⌘K, `?` overlay. Setup wizard audited from code (`setup-form.tsx`) because the e2e instance is already set up.
- Environment artefact, not counted: `notification.all` returns 500 in this DB (a row encrypted under a different `ENCRYPTION_KEY`); the page falls back to the `QueryState` error branch after the retry backoff.
- Also verified by API: zod validation errors are delivered to the browser as raw JSON (see F1).

## 3. Top 10 UX changes (ranked)

1. **Human-readable errors** — tRPC `errorFormatter` flattening zod to `field: message`, plus a client `describeError()` used by every toast (F1).
2. **Deploy pre-flight + follow the deploy** — reject unconfigured apps with a clear message, disable Deploy with a hint, and on success switch to Deployments and open the live log drawer; show last error under the header status (F2, F13, F22).
3. **Unify service pages** — one tab order, one `ServicePageHeader` (breadcrumb `Projects / project / env / service`, one status badge) for application, compose and the five databases; URL-sync the Advanced sub-tabs (F8, F9, F10).
4. **Unsaved-changes protection** — `useUnsavedChanges` hook (beforeunload + tab/route confirm), "Unsaved" pill next to each Save, one save bar per tab (F12).
5. **Unlock empty editors** — env/compose editors editable when empty, lock only with content or without write capability; inline "KEY=VALUE" hint instead of blur (F3).
6. **Getting-started checklist** — dashboard card with live checks (panel domain/TLS, Git provider, first service, domain, deploy) linking to each page; make setup next-steps buttons; create-application dialog takes the source up front (F5, F6).
7. **Type-to-confirm for cascades** — project and environment delete through `DangerZone` with a summary of what is removed (F4).
8. **Domain dialog guidance** — DNS record hint with the server's public IP, certificate select only with HTTPS, inline traefik.me/LE validation, per-domain "Check DNS" (F7).
9. **Activity tray + shared polling** — one running-operations query drives the hairline, header status, services table and a tray listing deployments/backups/restores with log links; poll only while something runs (F14, F31).
10. **Discoverability layer** — per-service palette destinations and shortcuts (`g l`, `g o`, `g e`), `HelpLink` to docs on every risky toggle, sentence-case label pass and shared date formatters (F15, F16, F17, F27).
