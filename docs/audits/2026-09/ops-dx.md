Date: 2026-09-10 · Tree: `work/stability-and-landing` (post stability sweep) · Scope: what to *improve*, not bugs.

## 3. Top 10 improvements (ranked by operator risk × leverage)

1. **Health/readiness/version endpoints** (#3) — unlocks safer rollbacks, install probes, CLI compat (#24), self-alerts (#10). M.
2. **Graceful shutdown + stop-grace + "no update while deploying"** (#2) — stops self-updates from corrupting tenant deploys. M.
3. **Pre-upgrade `pg_dump` + downgrade guard + `--update-monitor` in the in-app updater** (#6, #7) — makes "rollback" mean previous *state*. M.
4. **Release gate + PR builds** (#4, #16) — no tag/publish without green typecheck/test; PRs build web/landing/cli/image. S+M.
5. **Multi-arch images** (#1) — arm64 hosts stop building from source. M.
6. **Instance backup: `.env` handling, encrypted archive, verified restore script, DR checklist** (#5, #12). S–M.
7. **Platform self-alerts** (disk, queue age, cert expiry, platform services down, backup missing) (#10, #30). M.
8. **Install preflight + `uninstall.sh` + DNS/firewall guidance + offline recipe** (#13, #14, #15). S.
9. **Real e2e in CI** (boot built image, run golden path; then Playwright) and tests for observability/notifications (#17, #19, #20). L.
10. **Docs & DX on-ramp**: single operator env reference, troubleshooting + upgrade notes, cron "(UTC)" labels, SECURITY.md/templates/Dependabot, commit `dev.sh`, complete `.env.example` (#9, #21–#23). S.
