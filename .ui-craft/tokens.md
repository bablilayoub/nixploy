# Native component baseline

Source: https://ui.shadcn.com/r/colors/neutral.json and New York v4 registry.
Use the official Neutral light/dark values and radius 0.625rem. The user's explicit monochrome requirement overrides the registry's colored destructive and dark sidebar-primary defaults: those semantic roles resolve to primary/primary-foreground. No other palette customization.

Geist and Geist Mono are the existing fonts. Use shadcn stock variants. Layout spacing uses Tailwind scales; no new CSS skins. Existing operational CSS for scrolling, focus, reflow, reduced motion and touch remains.
